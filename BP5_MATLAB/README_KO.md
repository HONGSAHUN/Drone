# BP5 사진 기반 MATLAB 비행 시뮬레이션 — 초기 모델

제공한 BP5 제품 제원표와 실제 조립 사진을 참고한 외형 근사 모델입니다. 네 개의 가드, 분홍색 3엽 프로펠러, 상단 카메라와 전자장치 적층 구조를 단순 도형으로 표현합니다. 제조용 CAD나 실측으로 보정된 디지털 트윈은 아닙니다.

## 실행

이 폴더를 MATLAB의 현재 폴더로 선택하고 실행합니다. 기본 데모에는 MATLAB만 필요합니다.

```matlab
L = run_bp5_demo;          % 시뮬레이션, 결과 저장, 3D 애니메이션
```

```matlab
L = run_bp5_demo(false);   % 애니메이션 없이 계산/결과 그림 저장
test_bp5;                 % 물리 계산과 경로 추종 검증
bp5_animate(L,fullfile(pwd,'results','flight.avi')); % 선택: 영상 저장
```

`results/`에 `baseline.mat`, `baseline.csv`, `baseline.png`가 저장됩니다. CSV의 z는 지면 기준 질량중심 높이이며, 그래프의 고도는 착륙 상태 질량중심 높이를 뺀 값입니다. 모터 회전속도 단위는 CSV에서는 rad/s, 그림에서는 RPM입니다.

동봉한 `flight.mp4`는 1.3kg 모델의 20초 시뮬레이션 미리보기입니다. MATLAB에서의 애니메이션은 계산/그리기 속도로 재생되며, 저장 영상은 시뮬레이션 시간에 맞춘 25fps입니다.

경로는 18초 동안 대기 → 1m 이륙 → 오른쪽 1m → 왼쪽으로 2m → 중앙 복귀 → 하강하고, 이후 2초 동안 지면 도달과 모터 정지를 확인합니다. 18초 이후 지면에서 15mm 이내이고 수직 속도가 0.15m/s 미만이면 모터를 정지시키는 시뮬레이션용 착륙 로직을 사용합니다. x는 전방, y는 왼쪽, z는 위쪽인 오른손 좌표계를 사용합니다. `bp5_reference.m`에서 경로를 수정합니다.

## 확인된 값과 아직 모르는 값

| 항목 | 현재 반영 | 근거/상태 |
|---|---|---|
| 프레임 외곽 치수 | 285 × 292 × 35 mm | 사용자가 제공한 제품 제원표 |
| 프레임 키트 질량 | 약 120 g | 제품 제원표. 프레임 자체도 단순 상자로 근사 |
| 카본 판 두께 | 제원표의 1.5 mm | 자료로만 보관. 상세 판 형상·강성은 모델링하지 않음 |
| 프로펠러 | HQProp DP 5×4.5×3 V3 | 사용자가 알려준 부품명. 지름 5인치·피치 4.5인치·3엽으로 기록 |
| 배터리 제외 비행 중량 | 제품 표기 약 363 g | 참고값. 사용자의 완성 기체 질량으로 사용하지 않음 |
| 완성 기체 총질량 | **1,300 g** | 사용자가 알려준 배터리·카메라·보드 포함 비행 상태 무게 |
| 모터 중심 좌표 | x=±72.5, y=±76 mm | 외곽 치수와 사진을 참고한 가정, 실측 필요 |
| 카메라·보드·배터리 질량/위치 | 임시 부품 모델 | 사진만으로 질량을 식별할 수 없음 |
| 질량중심·관성행렬 | 부품 모델에서 계산 | 균일 상자 근사와 평행축 정리, 실측값 아님 |
| 추력 계수·반토크·최대 회전수·응답 속도 | 임시값 | 실제 모터·프로펠러·전압 자료 필요 |
| 항력 | 임시 선형 항력 | 가드의 유동 효과·지면 효과는 포함하지 않음 |

사용자가 알려준 모터는 RS2205-2300KV, 배터리는 UCELL 4S 14.8V 1550mAh 150C LiPo, FC는 MicoAirH743v2입니다. 이 부품명을 `P.hardware`에 기록했습니다. 카메라 제품명과 FC 펌웨어는 미확인입니다. 부품명 기록이 추진력·질량 파라미터를 실측값으로 바꾸지는 않습니다. KV는 RPM/V 단위의 모터 속도 상수이며, 단독으로 추력 계수가 되지 않습니다. 카메라의 시각적 배치와 질량 모델도 근사값입니다. CAD 없이도 시작할 수 있지만 사진만으로 정확한 관성이나 추진 성능을 알아낼 수는 없습니다.

총질량은 확인했지만 부품별 질량은 아직 미확인입니다. 기존 부품 가정값 합계 750g과 실제 총질량의 차이인 **550g을 `unlocated_mass`라는 추가 질량**으로 표현했습니다. 그 위치(프레임 중앙에서 위로 25mm)와 크기(160×160×100mm)는 임시 가정입니다. 따라서 1.3kg을 반영했다는 사실이 질량중심·관성이 확인됐다는 뜻은 아닙니다. 추가 질량은 물리 계산에만 사용하고 별도의 외형으로 그리지 않습니다.

## 실제 기체로 맞추는 순서

1. 비행 상태의 총무게는 사용자 제공 **1.3kg**을 반영했습니다. 이후 장비가 바뀌면 `P.measuredTotalMass`를 갱신합니다.
2. 앞뒤·좌우 모터 축 중심 사이 거리를 측정합니다. 프레임 바깥 치수와 모터 간 거리는 다릅니다.
3. 모터 모델/KV, 프로펠러의 지름·피치, 배터리의 셀 수/용량/무게를 확인합니다. 표시된 내용만 알아도 됩니다.
4. 가능한 부품별 무게와 설치 높이를 반영해 질량중심·관성 추정을 개선합니다. 총무게만으로 관성행렬이 결정되지는 않습니다.
5. 제조사의 해당 모터·프로펠러·전압 조합 시험자료가 있으면 추력 곡선과 최대 출력을 교체합니다. 이후 실제 비행 로그를 이용해 응답 특성을 보정합니다.

`bp5_params.m`에 부품별 `mass`, `xyz`, `size`와 추진 관련 값을 모았습니다. 부품 위치의 원점은 프레임 중앙입니다. 확인된 총무게 `P.measuredTotalMass`와 부품 추정값 차이는 추가 질량으로 맞추며, 질량중심과 관성은 그 분포로 계산합니다. 부품 추정값 합이 총무게를 넘으면 오류로 알려줍니다. `P.catalogDryMass`는 문서용 참고값이며 계산에 사용되지 않습니다.

## 포함된 물리/제어 모델

- Newton–Euler 6자유도 강체 운동과 SO(3) 회전행렬 적분
- 위치 PD + 속도/가속도 기준값 → 자세 PD → 모터별 추력 할당
- `F = kThrust * omega^2`, 모터 속도의 1차 지연과 출력 제한
- 부품별 질량중심을 반영한 추력 모멘트
- 지면 높이 제한과 단순 감속. Simscape의 다점 접촉 물리와는 다름
- 위치 추종 그래프, 회전속도 로그, 절차적으로 생성한 3D 기체

애니메이션 외형과 물리 모델은 같은 자세/위치 상태를 사용합니다. 공력 가드 효과, 구조 유연성, 프로펠러 간섭, 배터리 전압 강하, 센서 잡음·위치 추정은 아직 포함하지 않았습니다. 모터 출력 제한 시 단순 개별 클리핑을 사용하므로 큰 기동에서는 요청 토크와 실제 토크가 달라질 수 있습니다. 현재 모델의 RMS 수치는 가정된 모델 안에서의 추종 성능이며 실제 기체 정확도를 의미하지 않습니다. 이 제어기 계수를 실제 FC에 바로 적용하는 용도는 아닙니다.

## 강화학습 연결

첫 과제는 고도 1m의 호버링 보정입니다. 고전 제어기의 자세·모터 제어 루프를 유지하면서, 에이전트가 x/y/z 방향 가속도 보정값을 냅니다. 아직 학습된 에이전트나 학습 성능 결과는 없습니다.

- 관측 23개: 목표 위치 오차(3), 음의 속도(3), 회전행렬(9), 각속도(3), 정규화한 모터 속도(4), 남은 시간 비율(1)
- 행동 3개: [-1,1] 범위, 축별 ±2 m/s² 가속도 보정
- 보상: 위치 오차·속도·보정 크기 패널티와 생존 보상
- 종료: 8초 경과, 목표에서 2m 초과 이탈, 60도 초과 기울어짐, 지면 도달
- 초기 위치/속도 무작위화. 질량·추력 무작위화와 센서 기반 관측은 후속 확장

MATLAB만으로 환경 로직을 확인할 수 있습니다.

```matlab
[observation,info] = bp5_rl_reset();
[observation,reward,done,info] = bp5_rl_step(zeros(3,1),info);
```

Reinforcement Learning Toolbox가 있으면 공식 `rlFunctionEnv` 인터페이스로 연결합니다.

```matlab
env = make_bp5_rl_env();
validateEnvironment(env);
```

참고: [MathWorks 공식 rlFunctionEnv 문서](https://www.mathworks.com/help/reinforcement-learning/ref/rl.env.rlfunctionenv.html). `make_bp5_rl_env`는 연결 어댑터이며 학습 알고리즘이나 신경망은 아직 포함하지 않습니다. Simulink/Simscape 모델 생성은 이 초기 버전에 포함되지 않았습니다.

## 부품 자료 참고

- [EMAX RS2205 공식 제품 자료](https://shop.emaxmodel.com/products/emax-rs2205-racespec-motor-cooling-series): 사용자의 모터가 해당 EMAX 제품인지 확인이 필요합니다. 페이지의 추력 자료는 명시된 프로펠러 조합에서의 값이므로 현재 HQProp V3 조합에 그대로 대입하지 않았습니다.
- [MicoAir743v2 공식 설명서](https://micoair.com/en/docs/flight-controller/micoair743/micoair743v2-flight-controller-manual): 여러 펌웨어를 지원합니다. 실제 FC와 연결하는 단계에서는 현재 설치된 펌웨어와 버전도 확인해야 합니다. 이 초기 모델은 FC 펌웨어를 실행하지 않습니다.

## 이번 검증 결과

MATLAB R2024b Update 5에서 1.3kg 설정으로 기본 데모와 물리·제어 검증을 실행했습니다. 호버링 평형, 자유낙하, 모터 할당, 회전행렬 유지, 경로 추종, 착륙 지면 도달/모터 정지, 강화학습 환경의 0 보정 행동을 확인했습니다. 시뮬레이션 내부의 3차원 위치 추종 RMS는 약 0.0208m입니다. 이는 실제 기체와 비교한 모델 오차가 아닙니다. Reinforcement Learning Toolbox는 설치되어 있지 않아 `rlFunctionEnv` 어댑터 실행과 에이전트 학습은 검증하지 않았습니다.
